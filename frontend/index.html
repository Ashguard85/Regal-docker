Setup & Daten

Betriebsmodus, Verbindung und Backups

Betriebsmodus

Ein Moduswechsel wechselt nur den aktiven Datenspeicher. Daten werden nicht automatisch synchronisiert oder vermischt.

Verbindung / Server

Service-Tokens werden nur in IndexedDB auf diesem Gerät gespeichert, nie exportiert und nach dem Speichern nicht wieder vollständig angezeigt.

KI / Link-Auswertung

Aktiver Server-KI-Anbieter: –

Ollama wird ausschließlich vom Docker-Backend angesprochen. Die GitHub-Pages-PWA verbindet sich niemals direkt mit Port 11434. Im lokalen Pages-Modus wird keine KI verwendet.

Import / Export

Backups verwenden das gemeinsame Format brettspielregal-backup, Version 2. v1-Backups bleiben importierbar. Zugangsdaten sind nie enthalten.

Sicherheit & lokale Daten

Lokale Daten liegen nur auf diesem Gerät. Beim Löschen der PWA, der Website-Daten oder bei Geräteverlust können sie verloren gehen.

Für den Server-Modus empfiehlt sich ein separates, eng berechtigtes Cloudflare-Service-Token pro Gerät.
